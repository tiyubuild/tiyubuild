### What I'm building

- ZNTH Studios — GTA 6 Roleplay (in preparation): a server base pack + script suite for GTA 6 roleplay, a Discord bot and a licensing panel. Core logic separated from the game layer behind an adapter, so it ports to the new engine by rewriting only a thin layer.
- FiveM / GTA 5 Roleplay Servers: economy, inventory, jobs & permissions, in-game UI (phone, HUD, admin panel) and databases. Full architecture, implementation and live ops.
- n8n Automation: turns website form submissions into automatic confirmation & notification emails over SMTP.
